Auditly

Upload a support-call recording. It is transcribed, scored against your team's own QA guidelines on a 100-point basis, and comes back as a scorecard with cited evidence, Opportunities and Misses — then audited, coached and trended.

Open the live demo View the code on GitHub Read the README

Scores you can check

Every criterion comes with verbatim quotes and timestamps; the server drops anything it cannot find in the transcript and does the arithmetic itself.

Your own QA type

Paste the team's guidelines, extract weighted criteria, add a good and a bad sample per criterion, and save versions the scorecards remember.

Audit, coach, trend

A QA of record submits the final score, coaching sessions carry an agenda and a calendar invite, and the Dashboard shows the trends per agent and per QA.

Nothing to install

Python 3 standard library, one HTML page, SQLite. No packages, no build step. MIT licensed.

About the demo. It is this repository running in demo mode on a free host: fake providers, a fictional sample call and history, no keys and no sign-in. It is a shared sandbox that resets when the host restarts, and a sleeping free instance takes about half a minute to wake. Never upload a real call there.

About this page. GitHub Pages serves files only, so it cannot run the application; opening auditly.html here would show an empty sign-in form with no server behind it. Run it yourself with python3 auditly_host.py --demo.
